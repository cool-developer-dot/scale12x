# Scale12x

AI-native growth studio website — Next.js 16 + React 19.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Vercel deployment

1. Import `cool-developer-dot/scale12x` in Vercel
2. Framework: **Next.js** (auto-detected)
3. Root Directory: leave as repo root (this app)
4. Build Command: `npm run build`
5. Deploy

Or via CLI:

```bash
npx vercel --prod
```
